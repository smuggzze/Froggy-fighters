# Froggy Fighters

**Froggy Fighters** is a local 2-player pixel art fighting game built with Pygame. Players control frogs who battle it out using tongue attacks, movement, and platform mechanics. The last frog standing wins.

## Controls

### Player 1 (Green Froggy)

| Action       | Key        |
|--------------|------------|
| Move Left    | A          |
| Move Right   | D          |
| Jump         | W          |
| Duck         | S          |
| Attack       | Left Shift |

### Player 2 (Pink Froggy)

| Action       | Key            |
|--------------|----------------|
| Move Left    | Left Arrow     |
| Move Right   | Right Arrow    |
| Jump         | Up Arrow       |
| Duck         | Down Arrow     |
| Attack       | Right Shift    |

## Features

- Two-player local combat
- Pixel art style with scaling for clarity
- Health bar and life counter for each player
- Ducking, jumping, and tongue-based attacks
- Win screen with victory display and rematch option
- Basic gravity and collision system
- Animated movement and attack sequences
- Color-coded attacks and player sprites

## Requirements

- Python 3.x
- `pygame` library

You can install the required library using pip:


pip install pygame


## Running the game

run by typing "python froggy_fighters" in the console
